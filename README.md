# AKAN-NAME-GENERATOR
🌍Akan Name Generator is a simple web application that calculates the day of the week a user was born based on their birth date and assigns them a traditional Akan name according to their gender. The project is built using HTML, CSS, and JavaScript, providing an interactive way to learn about the Akan naming tradition of Ghana .
✨ Features
Enter your birth day, month, and year.
Select your gender.
Automatically calculates the day of the week you were born.
Displays your corresponding Akan name.
User-friendly interface with a Ghana-inspired theme.

🚀 How to Use
Open the application in your web browser.
Enter your birth date.
Select your gender.
Click Generate Akan Name.
View your Akan name and the day of the week you were born.
